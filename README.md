

新增批量图集：后端 /atlas 页面与 /api/atlas 接收 1～8 个独立拓扑圆盘 island，每项使用稳定字符串 id 与原求解请求 mesh。所有可用 UV 岛统一缩放到 [0,1]，仅允许平移与保持方向的 90 度旋转，不能逐岛缩放。padding 是归一化边缘及岛间距，必须小于 1/(岛数+1)。布局按稳定 id 可重复，但返回项顺序遵循请求；保留原岛、原面、面角、原顶点与切缝后的 UV 顶点身份。任一岛不可用时不导出部分图集；不要求最优排布。

实现位置与保证（已修复并加测试）：

- backend/packing.py：所有岛共用一个正比例 scale；逐岛只能平移或做 det=+1 的
  四分之一旋转 (u,v)->(-v,u)（旧代码 uv[:,[1,0]] 是 det=-1 的镜像，已删除）。
  行高均分的带式排布保证边缘与邻岛间距均为 padding；旋转只在严格改善适配时
  采用，平局保持 0 度，结果可重复。
- backend/app.py /api/atlas：严格校验请求（1～8 项、稳定非空字符串 id 且不重复、
  mesh 必备字段、有限且 0<=padding<1/(n+1)、非法 JSON 直接 400）；每个岛都走与
  /api/solve 完全相同的 split->圆盘校验->LSCM 路径；秩不足、翻转、退化、非有限
  坐标或输入非法都判定该岛不可用，整份图集拒绝（无任何部分输出）。布局按 id
  排序分配带位，但响应严格按请求顺序返回，坐标始终贴自己的 id，重排请求不会
  更换归属。/api/atlas/sample 返回一个可直接提交的三岛示例（故意乱序）。
- backend/static/atlas-view.js + atlas.html：按岛着色、绘制实际包围盒与统一边距、
  标注 id/带位/旋转角，悬停/点击显示 face/corner/orig_vertex/uv_vertex 身份，
  下载整份 atlas JSON。
- backend/tests/test_atlas.py：22 个测试覆盖公共缩放、形状/方向（带符号面积）、
  间距边界、重排归属不变、切缝 UV 顶点不按坐标合并、非法 padding/重复 id/非有限
  UV、任一岛不可用整批拒绝（含非圆盘见证）、非法 JSON 与示例端点。
