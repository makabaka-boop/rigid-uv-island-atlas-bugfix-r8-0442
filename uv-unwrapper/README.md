# LSCM 小网格 UV 展开工具

一个用于纹理绘制的教学型 UV 展开工具：React + Three.js 前端展示三维模型与
二维结果，Flask + NumPy 后端实现切缝分裂、拓扑圆盘校验和**手写**的面积加权
LSCM 最小二乘系统。最多处理 200 个三角形。

## 明确不做的事

- 不调用任何现成 UV 展开 / 参数化功能（无 igraph/libigl 参数化、无自动展开）；
- 不实现自动切缝，切缝边全部由用户点选指定；
- 图集不追求最优排布（只做稳定的分带布局）；
- 不做协同编辑。

## 运行

```bash
# 后端（127.0.0.1:5000）
cd backend
python3 -m pip install -r requirements.txt
python3 app.py

# 前端（127.0.0.1:5173，/api 已代理到后端）
cd frontend
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173/ 。

## 工作流

1. 选择示例（平面、合法切缝立方体、平面切入缝、封闭立方体/八面体等）。
2. 点工具栏“切缝边选择”，在三维视图中点击靠近某条边的位置加入/移除切缝
   （红线）。切缝会按**面片扇区**把原顶点拆成多个 UV 顶点，绝不按三维坐标
   去重。
3. 后端在 `/api/prepare` 拆分并校验：只有切开后是**一个拓扑圆盘**（面连通、
   恰一个边界环、χ=U−E+F=1）才允许求解；否则原样返回见证
   （`closed_surface` / `multiple_boundary_loops` / `disconnected` /
   `non_disk_characteristic`），界面显示，且不进行求解。
4. 切法合法时，二维面板显示 Tutte 预览（仅用于摆点选锚，不参与求解）。
   点“锚点选择”，在**拆分后**的边界顶点里依次选两个不同锚点，分别固定在
   (0,0)（绿）与 (1,0)（蓝）。
5. “求解 LSCM”：后端对每个三角形在局部正交标架中求帽子函数梯度
   `∇φᵢ = n×(pᵢ₊₂−pᵢ₊₁)/(2A)`，行按 `√area` 加权，组装
   `C_f = (U_x−V_y) + i(U_y+V_x)` 的 2F×2U 系统，代入两个锚点后用 SVD
   最小二乘求解（`numpy.linalg.lstsq`，通用求解器）。
6. 二维/三维点击同一个原始面互相定位，显示该面最大角误差、共形残差，并在
   两面板显示棋盘纹理；红面=定向翻转，橙面=退化。
7. “导出角点 UV / 面 ID”导出 JSON：每个面的三个角各一行，含 `face`（原面
   ID）、`corner`、`orig_vertex`、`uv_vertex`、`u`、`v`、角度误差。同一原
   顶点在切缝两侧会有不同的 `uv_vertex`，这是刻意行为。

## 多岛图集 `/atlas`、`/api/atlas`

一次提交 1～8 个独立拓扑圆盘，每项带稳定字符串 `id` 与原始 `/api/solve`
请求 `mesh`，外加归一化 `padding`（页面边缘与岛间距统一，必须
`0 <= padding < 1/(岛数+1)`）。`GET /api/atlas/sample` 返回可直接提交的
示例（请求顺序刻意与 id 排序不同，用于暴露错标问题）。

排布不变量（`packing.py` 与 `tests/test_atlas.py` 共同保证）：

- **一个共用正比例缩放**：所有岛使用同一个 `scale`，绝不同逐岛归一化；
  原大小不同的岛在图集中保持相对尺度（单元 3D 边在各岛内映射到相同图
  集长度）。
- **只平移 + 保向 90° 旋转**：旋转矩阵行列式恒为 +1；旧版 `(u,v)->(v,u)`
  是行列式 -1 的镜像，已移除。每个面排布后仍保持正绕序，岛形状不变。
- **统一边距/岛距**：所有岛都在 padding 内，带间间隙恰好为 padding。
- **身份跟随自身**：稳定 `id` 与其原面、面角、原顶点、切缝拆分后的 UV
  顶点始终成对；切缝两侧相同 3D 坐标的 UV 顶点仍保持独立，绝不按坐标合
  并。带位按 id 排序可复现，**返回顺序遵循请求顺序**；调整请求顺序只改
  输出顺序，不改变每个 id 的排布与归属。
- **整份成功或整份拒绝**：任一岛求解不可用（封闭曲面/非法切口/坏锚点/
  翻转或退化 UV）、id 非法/重复、padding 非法、JSON 非法时返回 400，
  不导出任何部分结果。

图集页按身份（非坐标）着色、悬停显示「岛 id·原面·各角原顶点/UV 顶点」，
并在浏览器端独立复核上述不变量；可下载完整 `atlas.json` 与逐角点
`corners.csv`。

## 如实报告的数值/拓扑问题

- 秩与秩不足：报告数值秩、预期秩和最小奇异值；秩不足时明确提示解不唯一；
- 残差：RMS 行残差、总面积加权能量、每面 `|C_f|` 共形残差；
- 翻转面 / UV 退化面：逐个面 ID 列出并在视图中叠加红/橙色，不把坏结果包装
  成可用贴图；
- 非法切口：返回见证，拒绝求解。

## 后端测试

```bash
cd backend
python3 -m unittest discover -s tests -v
```

`tests/test_pipeline.py`（19 个）覆盖：切缝分裂身份（缝两侧扇区独立、相同三维坐标不去重）、锚点约束
（精确固定 (0,0)/(1,0)、不同锚点、必须在边界）、平面小网格（共形残差≈0、
相似变换解、无翻转）、非法切口（封闭曲面、多边界环、断开组件、非流形边、
绕序不一致、退化面、超过 200 面、不存在的切缝边）、立方体可展面展开满秩、
导出角点行含面/角/UV 身份。

`tests/test_atlas.py`（23 个）覆盖：全岛共用一个正比例缩放（相对尺度与
单位边映射长度一致）、排布为 det>0 的纯相似变换（保向 90°，无镜像）、
稳定 id 始终跟随自己的原面/面角/原顶点/拆分 UV 顶点（含切缝顶点不按坐标
合并）、请求重排不改归属且布局对 id 可复现、统一 padding、id/padding/
数量/JSON 等非法输入整份拒绝（含一个岛不可用时不导出部分图集）。

## 文件

```
backend/
  mesh.py        输入校验 + 并查集扇区分裂
  topology.py    半边边界环追踪、圆盘判定、Tutte 预览
  lscm.py        面积加权 LSCM 系统组装 + SVD 求解 + 残差/翻转/角误差
  samples.py     平面/矩形/立方体/八面体示例
  packing.py     统一缩放 + 保向旋转的分带图集排布（身份跟随、整份校验）
  app.py         Flask API: /api/samples, /api/prepare, /api/solve,
                 /api/atlas, /api/atlas/sample, /atlas
  static/        图集页：按身份着色、不变量复核、JSON/CSV 下载
  tests/         19 + 23 个单元测试
frontend/
  src/ThreeView.jsx   三维模型、切缝、棋盘纹理、锚点球
  src/UVView.jsx      二维结果、棋盘、缝边、锚点拾取、面拾取
  src/App.jsx         状态与面板（拓扑状态/求解质量/面信息）
```
