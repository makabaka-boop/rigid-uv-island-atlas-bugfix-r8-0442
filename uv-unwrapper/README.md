# LSCM 小网格 UV 展开工具

一个用于纹理绘制的教学型 UV 展开工具：React + Three.js 前端展示三维模型与
二维结果，Flask + NumPy 后端实现切缝分裂、拓扑圆盘校验和**手写**的面积加权
LSCM 最小二乘系统。最多处理 200 个三角形。

## 明确不做的事

- 不调用任何现成 UV 展开 / 参数化功能（无 igraph/libigl 参数化、无自动展开）；
- 不实现自动切缝，切缝边全部由用户点选指定；
- 不做多图块（atlas）打包：只有一个拓扑圆盘、一套 UV；
- 不做协同编辑。

## 运行

```bash
# 后端（127.0.0.1:5000）
cd backend
python3 -m pip install -r requirements.txt
python3 app.py

# 前端（127.0.0.1:5173，/api 已代理到后端）
cd frontend
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173/ 。

## 工作流

1. 选择示例（平面、合法切缝立方体、平面切入缝、封闭立方体/八面体等）。
2. 点工具栏“切缝边选择”，在三维视图中点击靠近某条边的位置加入/移除切缝
   （红线）。切缝会按**面片扇区**把原顶点拆成多个 UV 顶点，绝不按三维坐标
   去重。
3. 后端在 `/api/prepare` 拆分并校验：只有切开后是**一个拓扑圆盘**（面连通、
   恰一个边界环、χ=U−E+F=1）才允许求解；否则原样返回见证
   （`closed_surface` / `multiple_boundary_loops` / `disconnected` /
   `non_disk_characteristic`），界面显示，且不进行求解。
4. 切法合法时，二维面板显示 Tutte 预览（仅用于摆点选锚，不参与求解）。
   点“锚点选择”，在**拆分后**的边界顶点里依次选两个不同锚点，分别固定在
   (0,0)（绿）与 (1,0)（蓝）。
5. “求解 LSCM”：后端对每个三角形在局部正交标架中求帽子函数梯度
   `∇φᵢ = n×(pᵢ₊₂−pᵢ₊₁)/(2A)`，行按 `√area` 加权，组装
   `C_f = (U_x−V_y) + i(U_y+V_x)` 的 2F×2U 系统，代入两个锚点后用 SVD
   最小二乘求解（`numpy.linalg.lstsq`，通用求解器）。
6. 二维/三维点击同一个原始面互相定位，显示该面最大角误差、共形残差，并在
   两面板显示棋盘纹理；红面=定向翻转，橙面=退化。
7. “导出角点 UV / 面 ID”导出 JSON：每个面的三个角各一行，含 `face`（原面
   ID）、`corner`、`orig_vertex`、`uv_vertex`、`u`、`v`、角度误差。同一原
   顶点在切缝两侧会有不同的 `uv_vertex`，这是刻意行为。

## 如实报告的数值/拓扑问题

- 秩与秩不足：报告数值秩、预期秩和最小奇异值；秩不足时明确提示解不唯一；
- 残差：RMS 行残差、总面积加权能量、每面 `|C_f|` 共形残差；
- 翻转面 / UV 退化面：逐个面 ID 列出并在视图中叠加红/橙色，不把坏结果包装
  成可用贴图；
- 非法切口：返回见证，拒绝求解。

## 多岛图集（/atlas）

`POST /api/atlas` 接收 1～8 个 `{"id": 稳定字符串, "mesh": 原 /api/solve 请求}`
及统一 `padding`。保证：

- **一个正比例缩放**作用于全部岛，禁止逐岛缩放，相对尺度不变；
- 只允许平移与**保持方向的 90° 旋转**（`(u,v)->(-v,u)`，行列式 +1），
  绝不交换坐标轴（那是行列式 −1 的镜像）；
- `padding` 同时是外边距和岛间距，要求有限且 `0 <= padding < 1/(n+1)`；
- 布局带位按稳定 id 排序、可重复，**响应顺序遵循请求**，每岛坐标与
  face/corner/orig_vertex/uv_vertex/面角身份永远贴自己的 id，切缝拆分出的
  UV 顶点不按坐标合并；
- 任一岛输入非法、不是圆盘、秩不足、有翻转/退化面或非有限坐标时，
  **整份图集拒绝（400）**，不导出任何部分结果。

`GET /api/atlas/sample` 返回故意乱序的三岛示例请求；页面在 `/atlas`。

## 后端测试

```bash
cd backend
python3 -m unittest discover -s tests -v
```

覆盖：切缝分裂身份（缝两侧扇区独立、相同三维坐标不去重）、锚点约束
（精确固定 (0,0)/(1,0)、不同锚点、必须在边界）、平面小网格（共形残差≈0、
相似变换解、无翻转）、非法切口（封闭曲面、多边界环、断开组件、非流形边、
绕序不一致、退化面、超过 200 面、不存在的切缝边）、立方体可展面展开满秩、
导出角点行含面/角/UV 身份；以及图集的公共缩放、方向保持、统一间距、
稳定 id 归属与整批拒绝（见 tests/test_atlas.py）。

  src/ThreeView.jsx   三维模型、切缝、棋盘纹理、锚点球
